# Student Management System Using a Dictionary

## 📌 Project Overview

The **Student Management System** is a beginner-friendly Python project that allows users to manage student records using a Python dictionary.

The system provides options to add, view, search, update, and delete student information through a simple menu-driven interface.

## 🚀 Features

- ➕ Add a new student
- 📋 Display all students
- 🔍 Search for a student
- ✏️ Update student information
- 🗑️ Delete a student
- 🚪 Exit the application
- 📚 Uses Python dictionaries to store student records

## 🛠️ Technologies Used

- Python 3
- Python Dictionary
- Functions
- Loops
- Conditional Statements
- User Input
