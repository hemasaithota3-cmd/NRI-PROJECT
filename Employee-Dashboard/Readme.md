# Employee Dashboard

## Project Overview

The Employee Dashboard is an Excel-based data analytics project that summarizes employee information and presents key business metrics using formulas, tables, and charts.

## Technologies Used

- Microsoft Excel
- Excel formulas
- Data analysis
- Data visualization

## Project Structure

```text
04-Employee-Dashboard/
├── employee_dashboard.xlsx
└── README.md
```

## Dashboard Features

- Total employees
- Total departments
- Average monthly salary
- Highest and lowest salary
- Total monthly payroll
- Estimated annual payroll
- Employees by department
- Average salary by department
- Employee distribution chart
- Salary comparison chart
- Detailed employee dataset

## Workbook Sheets

### Dashboard
Main visual dashboard with KPI cards and charts.

### Employee Data
Contains the detailed employee records.

### Summary
Contains formulas and department-level calculations used by the dashboard.

## Dataset Columns

| Column | Description |
|---|---|
| Employee ID | Unique employee ID |
| Employee Name | Employee name |
| Department | Department name |
| Job Role | Employee job role |
| City | Employee city |
| Monthly Salary | Monthly salary |
| Hire Date | Employee joining date |

## How to Use

1. Open `employee_dashboard.xlsx` in Microsoft Excel.
2. Start on the **Dashboard** sheet.
3. Open **Employee Data** to inspect the records.
4. Open **Summary** to inspect the calculations.
5. Change data in Excel if you want to practice updating the dashboard.
